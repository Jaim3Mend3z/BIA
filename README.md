# BIA — Bogotá Inteligente Asistente

BIA es un prototipo funcional de una plataforma web de asistencia ciudadana para Bogotá.

## Objetivo

Centralizar información relacionada con movilidad, eventos, salud, servicios ciudadanos y lugares de interés mediante una interfaz conversacional basada en inteligencia artificial.

## Estado

En desarrollo.

## Tecnologías

- React
- Vite
- Python
- FastAPI
- PostgreSQL
- PostGIS
- Docker
- NGINX
- DeepSeek API
- AWS
- GitHub

## Datos

El proyecto utilizará datos propios y datos simulados para representar determinadas integraciones con servicios de Bogotá.

Los datos simulados estarán identificados como tales y no representarán información oficial en tiempo real.

## Arquitectura

La aplicación seguirá una arquitectura web cliente-servidor con frontend React, backend FastAPI, PostgreSQL/PostGIS, integración con DeepSeek y despliegue mediante Docker y AWS.
